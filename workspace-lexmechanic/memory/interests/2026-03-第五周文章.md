### 技术向摘要

### 本篇关注重点
- **主题定位**: 车载以太网测试
- **核心问题**: 摄像头、域控制器、雷达、网关、中央计算平台之间的以太网链路，能否在车规噪声、温度、线束扰动、EMC 干扰和高速通信条件下可靠工作。
- **标准背景**: IEEE 针对汽车环境（重量限制、电磁干扰、严苛温度与振动环境）定制了车载以太网标准，包括 `100BASE-T1`、`1000BASE-T1`，以及更高阶的 `2.5G / 5G / 10G` 车载以太网。
- **主要测试层级**:
  1. **物理层测试**: 关注发射波形质量、幅度、抖动、上升/下降时间、回波损耗、插入损耗、模式转换、共模噪声，以及线缆与连接器带宽表现；目标是确认 `PHY + 线束 + 连接器 + PCB 通道` 组合后仍满足标准。
  2. **接收器一致性测试（Rx Test）**: 验证接收端在“恶劣但标准允许”的信号条件下，是否仍能正确恢复数据；通常会人为注入衰减、抖动、噪声、失真与干扰，以评估链路的现实环境抗性。
  3. **协议与一致性测试**: 检查 `MAC/PHY` 协议一致性、帧收发正确性、`VLAN / TSN` 支持、时间同步（如 `gPTP / IEEE 802.1AS`）、睡眠唤醒机制与错误恢复机制。
  4. **网络性能测试**: 观察吞吐率、端到端时延、时延抖动、丢包率、负载下稳定性以及多节点竞争场景下的表现，尤其关注安全相关流量与大带宽传感流量并存时关键报文是否准时送达。
  5. **EMC / 鲁棒性测试**: 关注抗辐射干扰、抗传导干扰、ESD 抗扰、瞬态脉冲影响，以及高低温和振动条件下的链路变化。
- **工程意义**: 重点不只是“能否连通”，而是验证车载网络在真实量产环境中是否具备可靠性、可预测性与可验证性。
