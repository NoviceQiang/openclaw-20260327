# memory/lessons.md

> 教训层：记录踩坑、错误、更优做法，避免重复犯错。

## 使用规则
- 记结论，不记冗长过程
- 每条尽量包含：问题 / 正确做法 / 严重程度 / 标签
- 只有可复用的教训才写入

---

## [L1] 身份冲突时的优先级
- **问题**: `USER.md`、`MEMORY.md` 中旧助手名称可能与当前身份冲突。
- **正确做法**: 若身份设定冲突，优先采用 `IDENTITY.md`，并同步修正其他记忆文件。
- **严重程度**: 高
- **标签**: #identity #memory #conflict

## [L2] 阅读兴趣关键词写入规则
- **问题**: 仅因“阅读文章”就写入兴趣关键词，会污染排序依据。
- **正确做法**: 只有当 Dominus 明确说“对这篇文章感兴趣”时，才提取最多 5 个关键词并累计权重。
- **严重程度**: 高
- **标签**: #reading #keyword #ranking

## [L3] memory 目录边界
- **问题**: 抓取产物、原始页面、测试文件、杂项资料混入 `memory/`，会削弱记忆层的可检索性。
- **正确做法**: `memory/` 仅保留分层记忆、interest 笔记、必要画像与规则文件；资料类与清理迁移项优先放入 `archive/` 或项目目录。
- **严重程度**: 高
- **标签**: #memory #cleanup #structure
