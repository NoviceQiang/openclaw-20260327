# Weekly summary format

Use this structure as the default template for `memory/weekly/YYYY-Www.md`.

```md
# YYYY-Www 周总结

- 状态：初稿 | 终版
- 周期：YYYY-MM-DD ~ YYYY-MM-DD
- 来源范围：memory/interests/*.md
- 条目数：N

## 本周主题分组

### 主题 1：<主题名>
- 核心判断：
- 涉及条目：
- 关键补充：

### 主题 2：<主题名>
- 核心判断：
- 涉及条目：
- 关键补充：

## 本周形成的关键判断
- 判断 1
- 判断 2

## 仍需补充 / 追问的问题
- 问题 1
- 问题 2

## 条目索引
1. 标题 — 链接
2. 标题 — 链接
```

## Draft update rules
- 初稿先覆盖主题框架与主要判断。
- 用户补充后，直接更新同一个周文件。
- 不创建“终版副本”或时间戳副本。
- 如果用户新增了更强的总结判断，把它提升到“本周形成的关键判断”。
- 如果用户只是补充某篇细节，把它放回对应主题下，不要打散整体结构。

## Grouping guidance
- Similar topics may share one theme section.
- Do not merge distinct engineering conclusions just because the vendors or application domains look similar.
- If one theme contains multiple articles on the same direction, keep a short per-article delta so later readers can still recover the differences.
